# cromor-holding

Maden & Mimarlık İnşaat - Kurumsal Web Sitesi

## Run Locally

**Prerequisites:** Node.js, npm

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key

3. Run the app:
   ```bash
   npm run dev
   ```
